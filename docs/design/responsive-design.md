# PC-first 响应式与无障碍规范

> 初步断点为建议值，必须以真实题目和视觉回归验证。与旧版 `frontend.md` 的实际 CSS 类名没有强制继承关系。

| 区间（建议） | 布局方向 | 行为 |
|---|---|---|
| 宽屏 ≥ 1100px | 顶部水平导航，4 科入口四列（按内容决定）；长读解可文章+题目双栏 | 阅读区域限制过长行宽；双栏不形成两个独立大滚动条 |
| 中屏 720–1099px | 入口可 2×2；主内容单列/适度双列 | 顶部 nav 可横向压缩，辅助信息移次行 |
| 窄屏 < 720px | 单列，选项通宽，目录纵向 | 顶部导航可采用紧凑替代导航，但四个核心入口仍一键可达，不增加多层菜单 |

## 常见场景

- **长篇文章**：文字区宽度符合舒适行长，必要时单列正文在上、问题在下；共享材料可提供返回文章位置的轻量定位，但不要无限嵌套滚动。
- **表格/信息检索图片**：自适应宽度并可局部放大，不能用 CSS `invert` 将扫描图变色；窄屏可以受控横滚或全屏查看。
- **听力**：固定底部播放器紧凑模式只保留必需播放/状态控制；页面滚动区留 `padding-bottom` ≥ 实际播放器高度 + safe-area；提交按钮不能被遮挡。
- **题目选项**：日文短语/长句/图像可自然换行；选择区触控目标建议 ≥44px；不将整行文字裁剪成省略号。
- **长题号**：`質問1`/`1番` 等印刷号不得压扁；在窄屏与题干允许换行。
- **弹窗确认**：移动端可底部抽屉，键盘/焦点与关闭后焦点恢复需要检验。

## 无障碍与视觉检查

- 用真实 N5 看图、N2 文法填空、N1 长阅读、N3 听力以及空题干样本验证。
- 选中、提交锁定、错误必须有文字或图标，不靠颜色；键盘 Tab 顺序正确；焦点可见。
- 尊重 `prefers-reduced-motion`；文本缩放 200% 时操作仍可达；检查浅色/深色（若启用）对比度。
- 避免路由切换时内容突然水平跳动；加载骨架和错误状态遵守同一个版式。

## 上线前设备验收

Chrome、Firefox、Safari 主流版本；桌面约 1440px、笔记本 1024px、平板 768px、手机 390px/360px。至少走通：选择题型→答题→未答确认→结果→历史，以及全流程听力播放器。
