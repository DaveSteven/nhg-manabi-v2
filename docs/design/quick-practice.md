# Quick Practice 快速练习交互规范

> **版本** v2.1 · 2026-11-17 · 设计体系：樱与墨 Modern Minimal · Desktop Only
> **所属模块**：历年试卷 / 单 Unit 快速练习（M2）。专项练习与完整模拟考试不走本流程。
> **v2.0 变更**：取消服务端草稿、刷新恢复与「继续旧练习？」冲突弹窗；Quick Practice 改为独立
> `quick_practice` 会话模式，随点随练，提交即完成并生成正式作答历史（ADR-0014）。
> **v2.1 变更**：文案按真实试卷结构动态化（提交答案/本组/本篇，下一题/下一组/下一篇）；
> 多题组内分页「上一题/下一题」；标题用试卷真实位置（問題1-3）；Layer 头部简化为
> 「已练习X/Y」数字高亮；去掉「第 1/1 组」与「已提交锁定」。

## 1. 设计目标

简化历年试卷普通练习：试卷详情点击 Unit 后**直接进入答题**——无模式选择、无会话配置、
无开始确认、无活跃会话冲突弹窗、无草稿保存/恢复。

固定流程：**进入 Unit → 选择答案 → 提交 → 查看反馈与解析 → 下一组 / 返回试卷**。

原则：随点随练；单 Unit 固定即时反馈；选择 ≠ 提交；已提交不可改；未答 ≠ 答错；
用户不需要理解 Session 机制；后端继续保证判题、答案权限与幂等（复用现有服务端机制）。

## 2. 三种练习场景

| 场景 | 交互 | 草稿/恢复 |
|---|---|---|
| 历年试卷单 Unit 快速练习 | Quick Practice，点 Unit 直接练 | 无（纯页面状态） |
| 专项练习 | 配置等级、题型、数量及反馈方式 | 服务端草稿 + 单一最近进度恢复（新开始即把旧进行中练习置 abandoned，ADR-0016） |
| 完整模拟考试 | 独立严格考试流程 | 独立会话机制 |

可复用渲染/判题/提交/反馈机制，但页面流程与会话模型不强行统一。

## 3. 会话模型（v2.0）

- 新增独立会话模式 `quick_practice`（`study_sessions.mode`，ADR-0014）：
  - 与专项/模考会话互不影响（专项自有单一最近进度槽 `ux_one_active_practice`，ADR-0016；quick 不占用它也不会被它替换）；
    quick 自己有单活跃索引 `ux_one_active_quick`。
  - 反馈方式固定 `immediate`，不接受配置。
- **静默替换**：开始新的 Quick Practice 时，同一事务内把旧的**进行中 quick 会话**置为
  `ended_early`（无弹窗、无二次确认）。旧 quick 会话最多只有未提交的本地选择（见 §4），
  本就不恢复，替换不损失任何东西；**绝不触碰专项/模考会话**。
- **提交即完成**：quick 会话只有一个 Unit，正式提交的同一事务内自动完成会话
  （`completed` + `study_results` 聚合成绩），不留长期进行中的会话。
  并发双击在 `ux_one_active_quick` 上兜底（后者 409，前端重试一次即可，赢家同样是新会话）。
- 不提供「恢复草稿」「进行中列表」：重新进入已练习 Unit 一律开始**新的**练习，
  历史作答不改（正式提交历史永久保留）。

## 4. 草稿（v2.0：无服务端草稿）

- 未提交的选项只保存在当前 React 页面状态中；**不调用** `PUT /drafts`，无自动保存、
  无保存状态徽标、无版本冲突弹窗。
- 页面刷新/离开 Unit 后，未提交的选择重置；重新进入 Unit 默认未选择状态。
- 不建立草稿箱或未完成练习列表。`study_answer_drafts` 表保留，专项练习继续使用。
- 前端不渲染「进行中/恢复草稿」状态；不能仅靠前端隐藏冲突弹窗——后端会话逻辑
  （模式隔离 + 静默替换）才是机制（ADR-0014）。

## 5. 试卷详情页

- Unit 列表为**紧凑整行可点**行：标题（問題1-2）、练习状态、题目数量、右侧 Chevron。
  点击即创建 quick 会话并进入练习；无任何确认弹窗。
- 练习状态（由当前用户真实作答历史计算，服务端 `/practice-status` 返回
  `practice_count` 语义的 `submitted_count`，前端不得自行累加）：

  | 条件 | 显示 |
  |---|---|
  | 没有正式练习历史 | 未练习 |
  | 正式练习过一次 | 已练习 1 次 |
  | 正式练习过多次 | 已练习 N 次 |

  不再显示「已提交/进行中」和粉色对勾状态。
- Layer 标题区域展示练习进度：X = 至少有一次正式练习记录的不同 Unit 数
  （重复练习同一 Unit 不增加 X），Y = 该 Layer 全部 Unit 数。可保留细进度条，
  不需要正确率或完成徽章。v2.1：提示简化为「已练习X/Y」（如 `已练习3/5`），
  数字以主色高亮，不再显示「组」字样与题数。
- 计数规则：以 Unit 为单位、按正式提交的 session-unit 记录统计；多 Question Unit 只计
  一次；幂等重复提交不重复计数；选择/进入/退出/刷新不计；未答提交成功仍计一次；
  专项练习对同一 Unit 的正式提交同样计入真实历史。
- 遵守 Canonical Unit 边界：独立题=单题 Unit；文法填空=整篇+全部题；读解=完整文章+关联题；
  听力=音频+材料+全部题。不得拆分共享材料 Unit。

## 6. 答题页

- 页面标题优先显示**试卷真实位置**（如 `問題1-3`，由大纲 Layer 标签 + Unit 位置推导，
  与目录行一致），不出现「练习 · 组 N」「第 1/1 组」等技术分组概念；提交后标题旁
  不显示「已提交锁定」（锁定由禁用的选项与提交后导航表达）。
- 文案按 Canonical Unit 的材料类型与题目数量动态选择：

  | Unit 类型 | 提交按钮 | 下一组文案 |
  |---|---|---|
  | 独立单题（single、单题听力） | 提交答案 | 下一题 |
  | 文法多题组（cloze/comparison 等） | 提交本组 | 下一组 |
  | 阅读文章（passage，含单题文章） | 提交本篇 | 下一篇 |

- 多题 Unit 内部按题分页：「上一题 / 下一题」，材料保持可见；分页仅为展示层导航，
  **正式提交仍整组一个事务**，绝不为了逐题展示拆分提交。
- 可选择、修改未提交答案；提交前不得展示受限答案/解析（服务端门控不变）。
- **提交规则**：全部已答 → 直接提交，无弹窗；存在未答 → 一次确认弹窗（标题
  「还有题目未作答」，内容「本组还有 X 题未作答。提交后将无法修改，确定继续吗？」，
  操作「继续答题 / 确认提交」）。未答题不自动判错。
- 提交后（即时反馈）：锁定答案，就地展示对/错/未答、正确答案与允许查看的解析，
  保留材料（原文/图/音频，含听力原文同门控揭示）；**不强制跳转独立成绩页面**；
  多题 Unit 可继续分页查看逐题解析。刷新/回访已完成的 quick 会话时，已提交选择经
  feedback 载荷回显（唯一合法来源）。
- 被新练习静默替换的旧 quick 会话页面：显示「本次练习已被新的练习取代」与
  「重新练习本组」入口。

## 7. 提交后导航

提交成功后就地反馈，并提供下一组入口与「返回试卷」。下一组 = **同一试卷**按原顺序
（Layer/Unit position）的下一个 Unit，开启**新的** quick 会话，文案按 §6 的 Unit 类型
显示「下一题 / 下一组 / 下一篇」；已是试卷最后一个 Unit 则**不显示**下一组按钮，
只保留「返回试卷」。不按 Question ID 推断。

## 8. Modal 使用原则

| 场景 | 弹窗 |
|---|---|
| 点击 Unit 开始练习 | 否 |
| 新练习与进行中 quick 会话同时存在 | 否（后端静默替换） |
| 新练习与专项/模考会话同时存在 | 否（模式隔离，互不影响） |
| 选择/修改答案 | 否 |
| 全部回答后提交 | 否 |
| 存在未答题时提交 | 是（一次） |
| 提交成功查看解析 | 否 |
| 返回试卷详情 | 默认否 |

## 9. 前后端职责

前端：轻量导航、未答确认弹窗、就地反馈、下一组与返回试卷、目录练习次数渲染。
后端：身份、quick 会话创建与静默替换、模式隔离、正式提交、幂等判题、提交即完成、
答案/解析/cues 权限门控、`practice-status` 真实历史统计。
**不能为减少弹窗绕过数据库约束或答案权限；客户端隐藏不是授权边界。**

## 10. 验收标准

见 Git 记录对应 devlog 的执行结果清单：直点即练且无任何冲突弹窗、全答直提、
未答一次确认、提交锁定并就地反馈与解析、刷新/离开重置未提交选择、再练产生独立
历史记录、重复提交不增加练习次数、多 Question Unit 只计一次、目录「未练习/
已练习 N 次」、Layer「已练习 X / Y 组」、quick 不影响进行中的专项练习、零答案泄漏
（提交前无正确答案/解析/cues）、专项与模考既有行为不受影响。
