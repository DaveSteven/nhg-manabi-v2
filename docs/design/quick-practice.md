# Quick Practice 快速练习交互规范

> **版本** v1.0 · 2026-11-17 · 设计体系：樱与墨 Modern Minimal · Desktop Only
> **所属模块**：历年试卷 / 普通练习（M2）。专项练习与完整模拟考试不走本流程。

## 1. 设计目标

简化历年试卷普通练习：试卷详情选择 Unit 后**直接进入答题**——无模式选择、无会话配置、无重复确认。

核心流程：**试卷详情 → 选择 Unit → 答题 → 提交 → 查看反馈与解析 → 下一题 / 返回试卷**。正常流程不出现确认弹窗。

原则：随点随练；单 Unit 默认即时反馈；选择 ≠ 提交；已提交不可改；未答 ≠ 答错；用户不需要理解 Session 机制；后端继续保证准确性与幂等。

## 2. 三种练习场景

| 场景 | 交互 |
|---|---|
| 历年试卷普通练习 | Quick Practice，点 Unit 直接练 |
| 专项练习 | 配置等级、题型、数量及反馈方式 |
| 完整模拟考试 | 独立严格考试流程 |

可复用渲染/Session/Draft/Submit/Feedback 机制，但页面流程不强行统一。

## 3. 试卷详情页

- Unit 列表为**紧凑整行可点**行：标题（問題1-2）、题目数量、必要的练习状态（✓ 已练）、右侧 Chevron。不保留行内大型「开始练习」按钮。
- 点击即进入练习；不出现模式选择/反馈方式选择/开始确认弹窗；无活跃会话冲突时直接创建 Session。
- 遵守 Canonical Unit 边界：独立题=单题 Unit；文法填空=整篇+全部题；读解=完整文章+关联题；听力=音频+材料+全部题。不得拆分共享材料 Unit。

## 4. 答题页

- 可选择、修改未提交答案、自动保存草稿、提交本组；提交前不得展示受限答案/解析。
- **提交规则**：全部已答 → 直接提交，无弹窗；存在未答 → 一次确认弹窗（标题「还有题目未作答」，内容「本组还有 X 题未作答。提交后将无法修改，确定继续吗？」，操作「继续答题 / 确认提交」）。未答题不自动判错。
- 提交后（默认即时反馈）：锁定答案，展示对/错/未答与允许查看的解析，保留材料（原文/图/音频）；不强制跳转独立结果页；多题 Unit 可显示组内统计。

## 5. 旧练习会话冲突

- 开始新 Quick Practice 而已有进行中普通练习时，显示**一次**冲突弹窗，不得静默结束旧 Session。
- 弹窗：标题「继续旧练习？」；内容「你还有一组未完成的练习。开始新练习将结束旧练习，已提交的答案会保留。」；展示旧练习等级/名称/进度；三个操作「取消 / 继续旧练习 / 开始新练习」。
- 取消=关弹窗保留现状；继续旧练习=进入恢复草稿与进度；开始新练习=原子替换后进入，**无第二确认**。已提交答案保留、未提交草稿不计分；后端成功后才跳转。
- **事务一致性**：优先后端原子「替换当前练习」（实现：`POST /api/practice/sessions` 的 `replace_active=true`，同一事务内结束旧（ended_early）+ 建新；并发重复请求由部分唯一索引兜底，不会产生两个进行中 Session）。若当前活跃 Session 已含该 Unit，直接恢复而非替换。

## 6. 反馈方式

历年试卷单 Unit Quick Practice 默认即时反馈，不显示反馈方式选择框。专项练习保留即时/统一反馈；完整模拟走严格交卷规则。

## 7. 提交后导航

提交成功后提供「下一题/下一组」与「返回试卷」；已是最后一组则不显示「下一组」。下一组按原试卷 Unit 实际顺序（position），不按 Question ID 推断。已提交 Unit 再次打开显示历史作答复盘；重新练习创建新作答记录，不改历史。

## 8. Modal 使用原则

| 场景 | 弹窗 |
|---|---|
| 点击 Unit 开始练习 | 否 |
| 选择/修改答案 | 否 |
| 全部回答后提交 | 否 |
| 存在未答题时提交 | 是（一次） |
| 新练习与旧 Session 冲突 | 是 |
| 结束旧练习后开始新练习 | 不重复确认 |
| 提交成功查看解析 | 否 |
| 返回试卷详情 | 默认否 |

## 9. 前后端职责

前端：轻量导航、自动保存状态展示、未答确认弹窗、旧练习冲突弹窗、就地反馈、下一组与返回试卷。后端：身份、Session 创建/恢复、单活跃约束、冲突处理、Draft 与版本、正式提交、幂等判题、答案/解析权限、历史记录。**不能为减少弹窗绕过数据库约束或答案权限。**

## 10. 验收标准

见 Git 记录对应 devlog 的执行结果清单：直点即练、无多余弹窗、默认即时反馈、整行可点、全答直提、未答一次确认、就地反馈、不强制结果页、冲突一次处理、无重复确认、草稿/提交区分、刷新恢复、共享材料不拆分、零泄漏、重复请求不产生重复会话或成绩。
