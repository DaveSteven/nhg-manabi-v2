# 模拟考试 UI（Exam Mode）

状态：用户 2026-11-18 确认的设计；说明页、考试框架（状态栏 + 答题卡）与作答布局已实现（见文末「实现状态」）。规则来源 ADR-0019 / ADR-0020，接口见 `development/api-conventions.md`。

## 结构
- 独立 **Exam Mode**（路由 `/mock/:sessionId`，不在 study 布局内，无站点导航）；说明页 `/study/exams/:examId/mock`；成绩页 `/study/mock/:sessionId/results`。
- 顶部 Sticky 状态栏：Logo · 考试名（`<级别> 模拟考试`）· 当前阶段与大题 · 已答 X / Y + 细进度条 · 剩余时间 · 「答题卡」按钮（所有题型位置一致，固定在倒计时右侧）。
- 倒计时基于服务端 `expires_at` 与 `server_now` 的偏差计算，刷新不变；≤5 分钟琥珀色、≤1 分钟红色，不闪烁。进度按当前阶段内已选择答案的不同 Question 数计，不按浏览数。
- 底部：大题「上一大题 / 下一大题」，最后一个大题处显示「结束当前阶段」/「检查并交卷」。

## 答题卡 Drawer
- 右侧 `position: fixed` 覆盖层（宽 400px，窄屏 100vw）+ 半透明遮罩；主页面不压缩、不重排、不重置滚动。关闭：×、遮罩、Esc、点击题号跳转后自动关闭；抽屉内部独立滚动。
- 头部「已作答 X · 未作答 Y · 标记 Z」；按真实大题（Layer 的 `display_label`）分组、可折叠，当前大题默认展开；题号状态：未作答白底灰边、已作答浅樱、当前题深樱白字、标记为右上角旗标（可与已答/未答并存）；不显示对错。
- 底部固定：「返回作答」+ 合法的阶段操作（结束当前阶段 / 检查并交卷）。点击后弹确认（已作答 / 未作答 / 标记数；返回检查 / 确认）。带未答交卷允许（未答 ≠ 答错）。
- 仅列出**当前阶段**的题，不能跳到其它阶段（阶段边界由服务端强制，接口对非当前阶段 Unit 一律 409）。

## 按题型的作答布局（同一套框架）
- 独立题/词汇/文法：整个大题一屏多题连续作答，不逐题提交；答题卡点题号自动滚动定位。选项按长度决定：所有选项 ≤24 字时宽屏 2×2，否则单列（ADR-0021）。
- 共享材料题（ADR-0021，取代按题型名的 flow 判定）：按材料结构只分三种模式——`cloze`（有 Slot 映射的文章填空）、`shared-material`（任何文字或图片共享材料，含 A/B、图文、信息检索）、`standalone`（无材料或听力）。共享材料统一左材料 58% / 右题目 42%（纯图片材料 62/38），右侧 Sticky 仅在本 Unit 内，避让考试状态栏。
- 一份材料一页（ADR-0023，取代「放得下全显示」）：共享材料大题一页只显示一个 Unit，底部「上一篇 / 下一篇」切换（大题首/末时回退为上一大题/下一大题或交卷）；多题 Unit 右栏恒为一次一题，面板顶部「‹ 上一题｜第 N 题 · i/n｜下一题 ›」，末题的下一题换成「下一篇 ›」；单题 Unit 无切换条。切题不动文章滚动、答案保留；切换材料保存并恢复各材料的当前题、滚动回顶；窄屏同样一次一题。
- 面板内选项：所有选项 ≤12 字才 2×2（如人名），读解长选项单列。
- 图片材料：点击图片在页内大图查看器打开（适应宽度 / 原始大小，Esc 关闭），查看器位于考试状态栏之下，倒计时始终可见；不再新开标签页离开考试。
- 答题卡跳转：目标在 Sticky 面板中时滚动到所在 Unit 顶部并切到对应题；当前题的滚动监听只认面板中的激活题。
- 听力连续播放（ADR-0022，优先）：听力阶段（每个 Unit 都有音频）且试卷有已落盘、有时长的完整录音时，整段录音连续播放。进入阶段先显示**确认页**（题量、录音时长、本阶段剩余、规则说明），点「确认开始听力考试」即在同一次点击中开始播放并进入答题页。播放器为底部居中的短胶囊（约 340×52px）：只有一个播放按钮（开始/继续；播放中为禁用态，永远不能暂停）和只读进度条，时间与状态只给读屏。整个阶段一个播放器实例，切大题、作答、打开答题卡都不影响。刷新后不再显示确认页，胶囊只提供「继续播放」（从服务器实时位置）。不做题号跟随。
- 听力逐题模式（兜底，无可用完整录音时）：每个音频一个「严格播放器」卡片，位于该 Unit 顶部，不使用普通练习的悬浮 Dock，无任何进度条拖动/暂停/倍速/回退/重播控件，不显示原文。点「开始播放（仅一次）」先在服务端登记开始时间，之后音频按**服务器时间线**走：位置 = 现在 − 开始时间；刷新或离开再回到该大题只能「继续播放」（从当前实时位置，不重头）；播放结束后永久不可再播。播放中不阻塞作答；浏览器暂停/拖动会被立即还原。不自动跳转下一题。

## 保存与恢复
选择即保存草稿（模考专用草稿接口，row_version 乐观锁，冲突需用户选择）；切题/大题不提交；保存失败在顶栏与题目处明确提示，不假装已保存。刷新后恢复阶段、草稿、所在大题、标记与剩余时间；交卷前不显示对错/得分/解析。

## 实现状态（2026-11-18）与边界
- 「标记待检查」仅保存在本机 localStorage（`minao-mock-flags:<sessionId>`），换设备不同步；后端无标记存储。
- 所在大题位置同样仅本机记忆；刷新后回到该大题。
- 成绩页（ADR-0027）：成绩概览（已作答正确率、已答 X/Y、答对/答错/未答、用时，无换算分/合格判定）→ 科目卡片（`已答 X/Y · 答错 X · 正确率 X%`，无有效作答显示「—」，点击只显示该科题号）→ 筛选（错误/全部/正确/未答）→ 紧凑题号网格（原始编号）→ 当前题复盘（复用专项 `ReviewQuestion`，上一题/下一题限当前筛选，切题/切科目/切筛选只换内容、不自动滚动页面（页面滚动由用户控制；回顾区预留最小高度防跳动），科目/筛选/题号记在 sessionStorage，解析与听力原文整场完成后经模考专用接口开放）→ 返回试卷/练习历史；试卷详情与练习历史均可进入同一页。
- 音频可用性（media_storage 已落盘）尚未作为模考开放条件；服务器无法阻止用户直接请求音频文件 URL（与普通练习同一媒体接口），严格性靠播放器与服务端计时线保证，不是防作弊边界。
- 逐题兜底模式下离开某个大题时声音会停止（服务器时间线继续走），回来后需点「继续播放」；一个大题内多个音频各自独立。
- 连续模式：阶段倒计时在确认页就已在走（阶段从上一阶段结束时开始计时），确认页停留会占用答题时间；是否改为确认后才开始计时待定。
- 浏览器内置窗格隐藏（视口 0×0），视觉/响应式未亲眼核对，仅用 JS 核对结构与真实数据流程。

## 视觉规范补充（2026-11-18 优化）
- Header：悬浮胶囊（Sticky，与站点 Header 同语言）；信息顺序与间距见代码 `_exam.scss`。
- 紧凑连续作答：卡片间距 16 / 内边距 16 / 题号→题干 8 / 题干→选项 10 / 选项 8；「标记待检查」在卡片右上；当前题仅淡粉底 + 樱色题号。
- 答题卡：410px、30% 遮罩、三个统计块、大题分组卡（`問題N · 已答/总数`）、5 列题号网格；头尾固定中间滚动；每次打开只展开当前题所在大题并定位；当前题由滚动位置决定。
- 倒计时：偏差只在收到新 `server_now` 时测一次，之后按绝对截止时间计算；后台标签页恢复可见时立即重算。
