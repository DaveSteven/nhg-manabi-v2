# 模拟考试 UI（Exam Mode）

状态：用户 2026-11-18 确认的设计；说明页、考试框架（状态栏 + 答题卡）与作答布局已实现（见文末「实现状态」）。规则来源 ADR-0019 / ADR-0020，接口见 `development/api-conventions.md`。

## 结构
- 独立 **Exam Mode**（路由 `/mock/:sessionId`，不在 study 布局内，无站点导航）；说明页 `/study/exams/:examId/mock`；成绩页 `/study/mock/:sessionId/results`。
- 顶部 Sticky 状态栏：Logo · 考试名（`<级别> 模拟考试`）· 当前阶段与大题 · 已答 X / Y + 细进度条 · 剩余时间 · 「答题卡」按钮（所有题型位置一致，固定在倒计时右侧）。
- 倒计时基于服务端 `expires_at` 与 `server_now` 的偏差计算，刷新不变；≤5 分钟琥珀色、≤1 分钟红色，不闪烁。进度按当前阶段内已选择答案的不同 Question 数计，不按浏览数。
- 底部：大题「上一大题 / 下一大题」，最后一个大题处显示「结束当前阶段」/「检查并交卷」。

## 答题卡 Drawer
- 右侧 `position: fixed` 覆盖层（宽 400px，窄屏 100vw）+ 半透明遮罩；主页面不压缩、不重排、不重置滚动。关闭：×、遮罩、Esc、点击题号跳转后自动关闭；抽屉内部独立滚动。
- 头部「已作答 X · 未作答 Y · 标记 Z」；按真实大题（Layer 的 `display_label`）分组、可折叠，当前大题默认展开；题号状态：未作答白底灰边、已作答浅樱、当前题深樱白字、标记为右上角旗标（可与已答/未答并存）；不显示对错。
- 底部固定：「返回作答」+ 合法的阶段操作（结束当前阶段 / 检查并交卷）。点击后弹确认（已作答 / 未作答 / 标记数；返回检查 / 确认）。带未答交卷允许（未答 ≠ 答错）。
- 仅列出**当前阶段**的题，不能跳到其它阶段（阶段边界由服务端强制，接口对非当前阶段 Unit 一律 409）。

## 按题型的作答布局（同一套框架）
- 独立题/词汇/文法：整个大题一屏多题连续作答（选项宽屏两列），不逐题提交；答题卡点题号自动滚动定位。
- 文章填空、短篇/长篇读解：沿用 `SharedMaterialLayout`（左文章 + 右 Sticky 题面板，Sticky 避让考试状态栏）；答题卡跳转通过 `focusRequest` 激活对应 Slot/题并定位，不重新加载文章。
- 听力：独立布局；严格播放器（只播一次、不可暂停/拖动）**尚未实现**，当前显示提示且不播放音频。

## 保存与恢复
选择即保存草稿（模考专用草稿接口，row_version 乐观锁，冲突需用户选择）；切题/大题不提交；保存失败在顶栏与题目处明确提示，不假装已保存。刷新后恢复阶段、草稿、所在大题、标记与剩余时间；交卷前不显示对错/得分/解析。

## 实现状态（2026-11-18）与边界
- 「标记待检查」仅保存在本机 localStorage（`minao-mock-flags:<sessionId>`），换设备不同步；后端无标记存储。
- 所在大题位置同样仅本机记忆；刷新后回到该大题。
- 成绩页为最小版（各阶段/科目答对数与正确率，无逐题回顾）；解析与听力原文在结果页的开放留待后续。
- 严格听力播放器与音频可用性开放条件未做；N1/N2 的听力阶段目前只能看到题目与选项。
- 浏览器内置窗格隐藏（视口 0×0），视觉/响应式未亲眼核对，仅用 JS 核对结构与真实数据流程。
