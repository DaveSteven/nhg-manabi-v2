# 用户端按钮与操作区规范 v1.0

更新：2026-11-17。适用于学生端及品牌页；管理端沿用独立设计体系。
本次将既有「樱与墨」方向细化为统一实施标准；仅更新文档，现有页面尚未全部迁移和验收。

## 1. 层级与形状

所有操作按钮（包括视觉为按钮的导航链接）统一使用 `--radius-pill: 999px`，不再由页面任选胶囊或中等圆角。文字链接、题号导航、Tab、题型卡片、选项和音频控件是独立组件，不强行套用按钮形状。

| 类型 | 默认样式 | 用途 |
|---|---|---|
| Primary 主按钮 | `--color-primary` 底、白字、同色 1px 边框 | 开始练习、提交答案、查看结果、再练一组等当前主要动作 |
| Secondary 次按钮 | `--color-surface` 白底、`--color-ink` 字、`--color-border` 1px 边框 | 上一题、下一题、查看答案与解析、返回专项练习 |
| Ghost 轻按钮 | 透明底、墨色字、透明 1px 边框 | 取消、低优先级局部辅助操作 |
| Danger 危险按钮 | 使用危险语义色，圆角尺寸同标准按钮 | 删除等破坏性确认；返回、换题不使用危险色 |
| Inline Link 行内链接 | 品牌色文字、有下划线，不加按钮外壳 | 说明文字中的跳转，如「去历年试卷」 |

同一操作区最多一个 Primary。主要等级按当前任务决定，不按 HTML 标签决定。结果页底部的「查看答案与解析」「返回专项练习」应使用 Secondary，不能因实现为链接就显示成裸文字链接。

## 2. 尺寸与排版

以下为 CSS px，不按截图的物理像素测量。统一 `box-sizing: border-box`、inline-flex 居中，无默认阴影。

| 尺寸 | 高度/最小高度 | 水平内边距 | 字号/行高 | 字重 | 图标 |
|---|---|---|---|---|---|
| Small | 36px | 16px | 14px / 20px | 600 | 16px |
| Medium（默认） | 44px | 24px | 16px / 24px | 600 | 20px |
| Large | 48px | 24px | 16px / 24px | 600 | 20px |

- 页面底部、练习、结果与弹窗操作统一 Medium；Small 仅用于紧凑桌面工具区；Large 仅用于明确需要的大触控入口，不因 Primary 自动加大。
- 同一操作区尺寸一致；「上一题/下一题」成对同宽，其余按钮按文字自然宽度。
- 图文间距 8px，按钮间距 12px，操作区与上方内容间距 24px。
- 窄屏允许整组换行，保持阅读与键盘顺序，不挤小字号；触控目标至少 44×44px，Small 在粗指针环境升至 Medium。
- 通常单行；长翻译或 200% 文本缩放允许换行并增高，不截断文字，不用固定高度裁剪。
- 图标按钮默认 44×44px，纯图标必须提供可访问名称。音频播放圆形按钮按 audio-player.md 独立规范。

建议落地为统一组件 Token（本次未修改 tokens.scss）：`--button-height-sm/md/lg` = 36/44/48px；`--button-radius` = `var(--radius-pill)`；`--button-padding-x-sm/md` = 16/24px；`--button-gap` = 8px；`--action-gap` = 12px。

## 3. 完整状态

| 状态 | 规则 |
|---|---|
| Hover | Primary 用 `--color-primary-hover`；Secondary/Ghost 用 `--color-primary-soft` 轻底色；不改变大小、边框厚度或上浮 |
| Pressed | 保持轮廓，使用轻微内阴影表达按压；不引起布局位移 |
| Focus-visible | 2px 品牌色外轮廓，offset 2px；不能用 hover 替代键盘焦点 |
| Disabled | 保留同尺寸轮廓，浅中性底、弱化文字；无 hover/pressed；不可触发。必要原因在附近说明 |
| Loading | 保留按钮宽度及层级，显示加载图标与动作文案，阻止重复触发，设置 aria-busy；不是改变主次样式 |

过渡统一 160ms，仅颜色、边框色与阴影；减少动态效果模式关闭过渡/非必要旋转。加载状态仍须有可读文字。正文对比度沿用 design-system.md 的验收目标，禁用态不能被拿来表达「已选中」。

## 4. 页面操作映射

| 场景 | Primary | Secondary / Ghost |
|---|---|---|
| 专项配置 | 开始练习 | 辅助说明中的「去历年试卷」用 Inline Link |
| 作答中、允许提交 | 提交答案 / 提交 / 提交本篇 | 已存在的上一题、下一题、返回操作为 Secondary |
| 已提交、继续练习 | 下一题 / 下一组 / 下一篇 | 上一题、返回；仅在业务允许时显示结果入口 |
| 已完成、答案复盘 | 查看结果 | 上一题、下一题、返回专项练习；下一题不得与查看结果同时为 Primary |
| 结果页 | 再练一组 | 查看答案与解析、返回专项练习 |
| 确认弹窗 | 确认当前动作 | 取消用 Secondary；危险确认用 Danger 取代普通 Primary |

业务决定按钮是否出现、可点击及何时揭晓答案；本表只规定视觉层级，不更改提交、会话或反馈权限。

## 5. 非操作按钮的独立规范

- **题号导航**：44×44px、12px 圆角，间距 8px；当前项用品牌色轮廓和字重并设置 aria-current，预留边框避免跳动。未答/已答/正误用标记及可访问文本区分，不只靠颜色。反馈未开放前不能用正误色泄漏答案；超长序号允许宽度增长。
- **题型选择卡片**：保留卡片圆角与信息排版，不受 44px 按钮高度或 56px 单行胶囊高度约束。单选组优先用 radio 语义，整卡可选；选中用浅樱底、品牌描边和可见选中标记，键盘可操作；初始未选择不自动冒充已选。
- **首页科目入口**：导航链接卡片，不是表单按钮；与专项页题型单选卡片区分。
- **Tab、主导航、答题选项**：分别沿用对应组件规范。选项是 radio，不用按钮禁用淡化样式掩盖提交后的答案。

## 6. 实施与验收

实现时统一 Button 与按钮外观的 Link 样式，显式 variant/size/loading；默认 button type=button，只有提交表单才用 submit。导航用真实链接，不能嵌套 button/a。链接不原生支持 disabled，需明确禁止导航及辅助技术状态，不能只降低透明度。

禁止页面选择器各自定义按钮圆角、高度、padding；布局容器只负责排列。先迁移专项配置、练习和结果页，再覆盖登录、账户及弹窗；本次不声称迁移完成。

验收：同排等高同圆角；最多一个主操作；返回动作外观一致；默认/hover/pressed/focus/disabled/loading 完整；375px 与桌面、200% 文本缩放无裁剪；键盘焦点可见；禁用/加载不可重复操作；已有反馈门控与会话行为不变。
