# 页面信息架构与关键界面

> 路由均为 **建议 URL**，非已经实现的 API/前端路由。依赖 `product/prd.md` 和 `design/design-system.md`。

## 全局导航

四项：**首页 / 专项练习 / 历年试卷 / 我的学习**，右侧头像设置。导航一级项不随题型动态增加。题目练习页可精简顶部操作，但必须可以返回。

## 首页 `/home`（核心确认）

```text
[顶部导航]
[继续上次练习 — 仅有 in_progress 普通 Session 时显示]
[文字词汇] [文法] [读解] [听力]        ← 第一视觉焦点
[历年试卷：快速查找]
[强化练习（次级）]    [考试倒计时（可选小字）]
```

不放大型欢迎 Hero、首页 tabs、连续签到卡堆叠或无数据时的“AI 洞察”。四学科入口直接进入该分类题型或最近配置的练习配置。优先真实快速进入。

## 专项练习 `/practice`

- 选 JLPT 等级；选**一个**具体题型；选择 Unit 数量（按题/篇/组显示单位）；反馈模式可选 `immediate`、`end`，当无实际差别时不额外造成一步操作。
- 展示可用题组数量与数据范围，数量超限明确提示，智能随机默认无需提供权重控件。
- 点击“开始练习”直接创建 Session；如已有旧活跃练习，先显示继续/替换。

## 试卷目录 `/exams`

- 页面内**没有筛选控件**（用户 2026-11-16 决定去掉等级与年份筛选）；等级跟随右上角备考等级选择器，未设置等级时显示全部等级，所有年份按最新在前列出。不硬编码 7月/12月 会期（没有时允许其他月份）。列表按**年份分行、最新年份在前**：每行两栏，左栏年份，右栏该年各会期的**胶囊卡片**（月份升序，如 `2026 ｜ 7月`、`2025 ｜ 7月 12月`），点击胶囊进入试卷（胶囊规范见 `design-system.md` §6.5，标准高度 56px）；未设置备考等级时胶囊内附等级标签。
- 不在列表每一行同时堆满模考/听力/随机/统计四个主要按钮。

## 试卷详情 `/exams/:examId`

```text
[返回列表] [N2 · 2018年12月]      [完整模拟（独立 CTA）]
[文字词汇] [文法] [读解] [听力]  ← 下划线 tabs
[問題 7] ▾
   ├─ 独立题 01 → 点击直达练习
   ├─ 独立题 02 → 点击直达练习
[問題 9] ▾
   └─ 文章填空（一篇 · 5小问）→ 点击直达整个 Unit
```

- 必须根据真实 Unit 分组，而不是凭同一 Layer 就合并所有 Question。
- 展开后展示题号、材料类型、题数、简短练习状态。可恢复短期返回时的科目/滚动/展开位置。
- “练习本大题”作为独立题串练入口仍是候选，不影响单 Unit 直达。

## 作答页 `/practice/:sessionId`

- 主内容为 Unit 材料 + Question/Option；独立题就地提交和查看解析。
- 多题材料用轻量题号定位、单页整组提交；宽屏长阅读可两列，手机单列；固定底部听力播放器不遮住按钮。
- 未答确认明确数量，禁止“改选就显示正确答案”。
- 如 Session 使用统一反馈，练习结束前不得展示 correct/wrong 状态。

## 我的学习 `/me/study`

建议三个扁平页面 tabs：`学习概览`（覆盖率、已答正确率、有样本量的弱项，行动入口）、`练习历史`（类型、日期、有效题数、结果与复盘）、`题目记录`（错题策略 B、收藏、最近已对/仍错筛选）。若设计测试后需调整页面组织，先改本规范。

## 模拟与结果

- 从试卷详情单独进入说明页，再启动经过核实计时规则的完整模拟。
- 严格模式页面保留服务端 Phase 时间、未答题号和正式交卷，禁止随意使用普通听力的拖动/倍速。
- 结果页按正确/错误/未答独立统计；单题普通练习就地反馈，不开无意义大结果页。

## 管理端（最小）

`导入批次列表 → 批次详情/校验异常 → Unit/Question 审核 → 发布决策 → 版本回顾`。管理端可沿用 1.0 批量校验的思路，但状态契约变为 canonical content hash + review result + immutable release。
