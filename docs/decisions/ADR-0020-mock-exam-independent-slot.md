# ADR-0020 模考使用独立名额，与练习互不冲突

状态：已接受（用户 2026-11-18）。**取代 ADR-0019 的 M8**（其余 M1–M10 不变）。

## 背景
ADR-0019 M8 规定练习与模考共用单进程、互相直接替换且不弹确认。实现后发现：误点「开始练习」会静默放弃一场计时中的模考，模考丢失不可恢复，而练习可恢复，两者代价不对等；且模考计时在服务器端，并行做练习在技术上没有障碍。

## 决定
1. 模考拥有**自己的单名额**（`ux_one_active_mock`）；专项/普通练习名额（`ux_one_active_practice`，ADR-0016）与 Quick 名额（ADR-0014）不变。三者互不影响：开始任一种都不会放弃另外两种。
2. 同一用户已有进行中模考时再次开始模考：服务端返回 409 `mock_in_progress`（带进行中会话 id 与 exam_id），前端提示「继续当前模考」；只有请求显式带 `replace_active=true` 才放弃旧模考（已正式提交的 Phase 答案保留、不产生成绩）。已到期的模考（惰性封存后为 completed）不阻止新模考。
3. 模考计时与练习并行：用户去练习时模考时钟照常走，到期后下次访问惰性封存。前端需在练习页/顶栏提示「模考进行中 · 剩余时间」（前端步骤实现）。
4. 其余不变：模考答案不进练习统计与历史；单名额由 DB 部分唯一索引兜底。

## 实现
Alembic 0014：`ux_one_active_main`（0013 引入，未部署）换回 `ux_one_active_practice` + `ux_one_active_mock`；创建练习不再放弃模考；创建模考不再放弃练习。
