# ADR-0004：不可变发布内容与跨卷会话

- 状态：已采用的设计方向（发布合规及具体实现仍需验收）
- 日期：2026-11-15

## 决定

正式发布时内容/答案/解析与资源引用形成不可变 release。历史 Session Unit 固定 release_id；普通随机允许跨年份，模考固定整卷 release。修正答案以新版本和单独 regrade 事件处理，禁止静默覆盖旧成绩。

## 理由

减少来源耦合、维护成本和历史记录污染，同时保持小团队可实现的复杂度。

## 影响

更改本决策必须同步更新 `docs/decisions/README.md`、对应业务规范、数据库/接口测试，迁移已发布内容需要单独评估。
