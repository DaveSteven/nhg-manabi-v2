# ADR-0021 模拟考试：按材料结构自动适配的共享材料布局

状态：已接受（用户 2026-11-18 提出统一布局方案，并采纳评审修订「按修订版实现」）。仅模拟考试页；普通/专项练习页仍按 ADR-0018。不改后端与数据模型。**第 3 条（放得下全显示）已被 ADR-0023 取代。**

## 背景
旧实现有两处按名称/偶然条件分支：`usesSplitLayout` 只在有文字材料时分栏（信息检索 105 个纯图片 Unit 退回上下堆叠）；`mockModel.isFlowType` 按 `reading_short`/`reading_short_set` 题型名决定是否 Sticky。读解选项一律宽屏 2×2，而真实数据读解选项中位数 27–39 字、P90 36–60 字，在约 480px 的右栏里每格只容约 13 字，折成 3–4 行。

## 决定
1. **三种模式，按材料结构判定**（`layoutModeOf`）：含音频 → `standalone`（听力自有布局）；有文字材料且有 Slot 映射 → `cloze`；有文字或图片共享材料 → `shared-material`；其余 → `standalone`。不按长篇/短篇/图文题型名分类。
2. **双栏比例**：桌面 ≥1024px 左 58% / 右 42%；纯图片材料 62% / 38%（扫描件字小，右侧选项短）。材料随页面滚动，右栏 Sticky 仅在本 Unit 容器内、避让考试状态栏；A/B 材料在材料栏内上下排列。
3. **放得下全显示，放不下才切换**（修订原方案「多题一律一次一题」）：渲染前以全部显示状态测量右栏内容高度，≤ 屏高 − 面板 Sticky top − 24px 则全部显示、不显示题号条；否则一次一题 + 题号条。从「切换」回到「全显示」需多留 40px（回滞防抖）。窗口尺寸/内容尺寸变化时重算。窄屏堆叠时始终全部显示。理由：短篇组（277 个 Unit、2–3 题）在常见屏幕上全部可见，保留「先看题再读文」习惯并避免漏答。
4. **题号条状态**与答题卡一致：已答浅樱底、标记待检查右上圆点（读屏文本「已作答 / 已标记」）。切换不重置文章滚动，所有小题保持挂载、答案保留。
5. **选项列数按字数**：所有选项可见字数 ≤12（面板内）或 ≤24（整宽卡片）才宽屏 2×2，否则单列；按字数而非渲染测量，避免布局跳动。
6. **图片放大**：页内查看器（适应宽度 / 原始大小，Esc 或关闭按钮退出），位于考试状态栏之下，倒计时始终可见；不再新开标签页离开考试。
7. **答题卡联动**：目标题在 Sticky 面板时滚动到所在 Unit 顶部并激活该题；当前题滚动监听只认面板中的激活题；阶段导航权限不变。

## 后果
- 删除 `isFlowType` 与 `.is-flow` 样式；`SharedMaterialLayout` 新增 `adaptive`、`chipState`、`onActiveChange`，练习页未传 `adaptive`，行为不变。
- 风险：`media_assets` 不存图片宽高，图片加载完成前材料栏高度会变化（不影响右栏测量结果，但页面会有一次位移）；后续可在导入时记录尺寸。字数阈值基于 15px 正文与当前栏宽估算，换字号或栏宽时需复核。
