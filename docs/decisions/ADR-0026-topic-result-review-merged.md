# ADR-0026 专项练习结果页与答案解析页合并

日期：2026-11-18。状态：已确认（用户需求）。

## 背景
专项练习完成后先到 `/results`（成绩 + 逐题列表），再点「查看答案与解析」回到练习页复盘，两页往返、信息重复（得分率/已作答正确率）。

## 决策
1. 专项练习（`config.topic` 存在）的结果与解析合并为 `/study/practice/:sessionId/results` 单页：成绩概览 → 题号导航 → 当前题与解析 → 底部「再练一组」「返回专项练习」。
2. 正确率只显示一项，按已作答（对/(对+错)）计算并标注口径；不再显示得分率。
3. 题号按原始作答顺序；默认选中首个错题，否则第一题；切题为本地状态，不重新请求 `/results`。
4. 完成后访问 `/study/practice/:id`（已完成专项会话）跳转至合并页；即时反馈与统一反馈都走同一页；练习历史入口原本即指向 `/results`。
5. 不新增后端接口：成绩与正误来自 `/results`，解析来自受门控的 per-unit `/feedback`（会话完成后）；历史只读，不重算。
6. 范围外：Quick Practice（就地反馈）、非专项普通会话（沿用原结果页）、模拟考试。

## 影响
纯前端路由/页面变更；未改答案可见性与门控。ended_early / abandoned 仍显示原提示页。
