# ADR-0019 严格模拟考试规则

状态：已接受（用户 2026-11-17 逐条确认 M1–M10，M8 由用户修改）。规则**已定**。进展：Phase 数据层（2026-11-17）与**模考后端（2026-11-18，迁移 0013 + `/api/mock-exams`）**已实现；前端、严格听力播放器未开始，功能对用户尚未上线。

## 决定

1. **Phase 与时限（M1）**：按官方考试结构划分，分钟数取自 JLPT 官网 *Test Sections and Time Allotted*（https://www.jlpt.jp/e/guideline/testsections.html，2026-11-17 核对；官网注明时间可能调整，以 release 记录的数值为准）。

   | 级别 | 言語知識（文字・語彙） | 言語知識（文法）・読解 | 聴解 | 合计 |
   |---|---|---|---|---|
   | N1 | 与后项合并 | 110 | 55 | 165 |
   | N2 | 与后项合并 | 105 | 50 | 155 |
   | N3 | 30 | 70 | 40 | 140 |
   | N4 | 25 | 55 | 35 | 115 |
   | N5 | 20 | 40 | 30 | 90 |

   N1/N2 为 2 个 Phase（「言語知識（文字・語彙・文法）・読解」+「聴解」），N3–N5 为 3 个 Phase。
2. **数据归属（M2）**：时限与播放策略写入不可变 Release 的 `release_exam_phases`（`duration_seconds`、`playback_policy`），由转换器按级别规则表生成；规则表入库并注明来源。已发布的旧 release 不回改，需新 release 才有模考入口。
3. **听力（M3）**：严格模拟每段音频只播一次，不可暂停/倒退/拖动，倍速关闭；使用与普通练习分离的播放器模式，服务器记录播放开始。
4. **超时（M4）**：服务器 `study_phase_runs.expires_at` 为准；到期自动封存当前 Phase——已有草稿按已选答案正式提交，未选为 skip（skip ≠ wrong）。客户端倒计时仅展示。
5. **Phase 间（M5）**：按顺序进入，关闭后不可回看/修改；提前交卷的剩余时间不顺延。
6. **暂停/断网（M6）**：不可暂停；断网期间计时继续；重连按服务器时间恢复；关闭页面不等于结束。
7. **成绩（M7）**：只给各 Phase/科目答对数与正确率；不做官方换算分或合格判断；模考与练习成绩分开展示、不混入练习统计。
8. **名额（M8，已被 ADR-0020 取代：模考独立名额、与练习互不冲突）——原决定如下：**：用户通常一次只做一件事，**练习与模考共用「单进程」语义，互相直接替换，不弹确认**：开始模考即把进行中的专项/普通练习置 `abandoned`；开始新模考直接替换旧模考；开始练习若有进行中模考同样直接替换。被替换会话已正式提交的答案保留、不产生成绩、未提交草稿不计。Quick Practice 仍是独立轻量名额，不受影响（沿用 ADR-0014）。
   - 影响：这需要数据库层把 `ux_one_active_practice` 与 `ux_one_active_mock` 合并为同一用户单一进行中约束（或同事务互相 abandon），实现时须新 Alembic revision 并验证真实 PG。
   - 风险：误触「开始练习」会静默放弃一场计时中的模考。如需要保护，可后续改为仅对模考加一次确认；本 ADR 按用户指示不加。
9. **答案泄漏（M9）**：最后一个 Phase 关闭（交卷或超时）前，任何接口不返回正确选项、解析、听力原文；交卷后才开放逐题回顾。使用模考专用题目 DTO，不复用 practice 的 unit/feedback 接口。
10. **上线范围（M10）**：只有 Phase 与时限齐全的试卷显示模考入口；缺 Phase 的试卷不显示，也不降级成无限时「模拟」。

## 参考 V1（只读背景，不照搬）

V1 `exam_runs` 以 `section_expires_at` 由服务端控制分节时限、进行中逐题草稿（run_answers）与完成后落成绩场次/逐题快照（attempts/attempt_answers），前端做 JLPT 换算分。V2 沿用「服务端是进行中会话唯一事实源」与「草稿→交卷落正式答案」，但**不做换算分**，答案快照与 release 追溯沿用 V2 的 `study_submitted_answers`。V1 文档未记录各级别分钟数，故时限以官方公布为准。

## 实现备注（2026-11-18 后端）

- 单名额（已由 ADR-0020 / Alembic 0014 改回独立名额）：0013 曾以 `ux_one_active_main` 合并练习与模考，随后撤回。`study_phase_runs` 增加每 Phase 仅一次、每会话仅一个未关闭 run、`expires_at > started_at`。
- 到期封存为惰性（请求触发，无后台任务）；下一 Phase 自上一 Phase 到期时刻起算。M7「不混入练习统计」落实为：模考答案不写 `user_question_progress`，不进练习历史。
- 暂未实现（留给后续步骤）：严格听力播放（播放一次/服务器记录播放开始）、音频资产可用性作为模考开放条件、逐题解析与听力原文在结果页的开放、模考成绩列表入口、前端。
