# ADR-0034 题目阅读字号设置

- 状态：已确认（2026-11-24，用户决定）
- 决定：新增三档「题目字号」（标准 1× / 大 1.125× / 特大 1.25×），**只缩放题目阅读内容**（题干、选项、材料、解析，即 `.richtext`）；导航、头像、按钮、标题梯度等界面不变，H1–H6 字号（§7.2）不受影响。
- 实现：`<html>` 上的 CSS 变量 `--reading-scale`，`.richtext { font-size: calc(1em * var(--reading-scale)) }`；偏好存浏览器 localStorage（`jlptgo.readingSize`），暂不同步服务端 profile，换设备不跟随。
- 入口：用户中心「阅读设置」（三选一）；练习页头部与严格模考顶栏的紧凑「Aa」循环按钮。
- 取舍：不做滑块，减少视觉验收组合；不整站缩放，避免顶部导航在窄屏换行。如后续要跨设备同步，再加 profile 字段与迁移。
