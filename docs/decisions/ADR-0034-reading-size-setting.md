# ADR-0034 题目阅读字号设置

- 状态：已确认（2026-11-24，用户决定）
- 决定：新增五档「题目字号」（标准 1× / 稍大 1.125× / 大 1.25× / 特大 1.375× / 超大 1.5×，2026-11-24 由三档调整），**只缩放题目阅读内容**（题干、选项、材料、解析，即 `.richtext`）；导航、头像、按钮、标题梯度等界面不变，H1–H6 字号（§7.2）不受影响。
- 实现：`<html>` 上的 CSS 变量 `--reading-scale`，`.richtext { font-size: calc(1em * var(--reading-scale)) }`；偏好存浏览器 localStorage（`jlptgo.readingSize`），暂不同步服务端 profile，换设备不跟随。
- 入口：「字号设置」按钮（用户中心、练习页进度行、严格模考顶栏的「字号」），点击弹出带刻度滑轨（吸附五档）和题目预览的对话框，含「恢复标准」。
- 取舍：滑轨吸附到固定档位而非连续值，保持有限的验收组合；不整站缩放，避免顶部导航在窄屏换行。如后续要跨设备同步，再加 profile 字段与迁移。
