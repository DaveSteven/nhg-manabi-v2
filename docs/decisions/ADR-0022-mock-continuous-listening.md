# ADR-0022 模拟考试听力：完整录音连续播放 + 底部 Mini Player

状态：已接受（用户 2026-11-18：方案「统一连续播放 + Mini Player」，随后确认「直接用完整音频」「不需要跟着题号走」「exam-mini 为约 300 多像素的短条，只有播放按钮和进度条，放在底部」「听力加确认页，确认后进入答题页自动播放」）。扩展 ADR-0019 M3（只播一次、服务器时间线）。

## 背景（数据核查）
- 本机库 105 套 current release 都有 `full_audio`（整卷听力录音，`media_storage` 已落盘且有校验时长）。每个听力 Unit 另有一段上游切好的片段（原始资源中即存在，转换器不剪辑）。
- 片段只含题目本身，不含大题说明、例题和作答间隔：N2 2026-07 整卷 40:21，片段合计 31:56。拼接片段会丢内容。
- 片段可在整卷中定位（抽查 5 套 142 段，相关度 ≥0.86、顺序一致），但数据中无时间点；用户决定不做题号跟随，故无需对齐、无需重导数据。

## 决定
1. **音源**：听力阶段（阶段内每个 Unit 都有音频素材）且试卷有已落盘、时长 > 0、未损坏的 `full_audio` 时，整个阶段只播这一段完整录音。否则沿用逐题严格播放器（ADR-0019 M3 原实现）。
2. **服务器时间线**：新表 `study_phase_audio_plays`（Alembic 0016，PK session+phase，只插入）。`POST /api/mock-exams/{id}/phases/{phaseId}/audio/start` 幂等登记开始时间，仅当前进行中阶段可开始；位置 = now − started_at，刷新只能从实时位置继续，时长走完永久结束。
3. **不泄漏片段**：连续模式下 `/content` 不再下发各 Unit 的音频素材，逐题 start 接口返回 409 `continuous_audio`，单题无法单独重播。
4. **确认页**：阶段录音未开始时先显示确认页（题量、录音时长、本阶段剩余、规则）。「确认开始听力考试」在同一次点击中同步调用 `audio.play()`（满足浏览器用户手势要求），随后服务端登记并校正位置（被拒则停止并提示）。刷新后（已开始）不再显示确认页。
5. **exam-mini**：复用 `StrictAudioPlayer`，新增 `exam-mini` 形态：底部居中固定的短胶囊（约 340×52px），只有一个播放按钮（开始/继续；播放中为禁用态）与只读进度条；状态与时间仅提供给读屏。整个阶段一个实例，挂在大题页面之外，切大题、作答、打开答题卡不重建、不暂停。
6. **规则在播放器逻辑层**：暂停立即恢复（系统拒绝时明确提示「继续播放」）、拖动还原到实时位置、倍速改动立即复位 1×；无 controls、无 range。
7. **不做**：题号跟随与自动滚动（用户取消）；听力原文与解析在考试中不下发（沿用）。

## 后果 / 风险
- 阶段倒计时从上一阶段结束即开始，确认页停留会占用本阶段时间；是否改为确认后计时另行决定。
- 媒体接口不区分模考，直接请求 URL 仍可下载录音（与 ADR-0019 实现备注一致，不是防作弊边界）。
- 网络缓冲导致的落后不会被拉回到服务器位置（只在拖动时校正）；刷新/继续会对齐。
- 练习页播放器（AudioDock）未改动。
