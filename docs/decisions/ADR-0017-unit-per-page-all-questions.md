# ADR-0017 成组题一页展示全部小题，不再小题分页

状态：已接受（用户 2026-11-17 指示）。局部修订 Quick Practice v2.1 与统一反馈练习的「上一题/下一题」交互；不改变数据模型、判题或反馈门控。

## 决定

1. 文法成组题、阅读多问等多小题 Unit，一页展示共享材料 + 该 Unit 的**全部小题**，小题之间不再有「上一题/下一题」。
2. 统一反馈专项练习的步进单位由「题」改为「Unit」：按钮按类型显示 上一/下一 组、篇、题（独立单题仍逐题）；进度文案「第 x / M 组 · 第 a–b / N 题」。
3. 题号条保留逐题状态与复盘对错；点击跳转到所在 Unit 并滚动到该小题。
4. Quick Practice 多题 Unit 同样列出全部小题；整组一个事务提交不变。
5. 草稿保存、整次一次性提交、未答确认（仅最后一页一次）、反馈门控全部不变。

## 影响
纯前端展示层；后端、Schema、API 未改。长阅读双栏（材料固定）留待后续。
