## 尚未定稿的重点

- 读解题型 `32–36` 语义字典最终名称；N1/N2 A/B 材料启发式拆分复核。
- 严格模拟各阶段时限/播放行为、暂停与断网规则；官方换算分不可未经验证伪造。
- 旧用户及历史数据迁移、完整注册策略；内容/媒体授权审查机制。
- 主题暗色具体色板、容器上限和响应式断点、统计时间范围。
- “练习本大题”快捷入口、普通听力倍速/拖动等交互细节。
