# ADR-0024 模拟考试：听力确认后才计时 + 主动放弃考试

状态：已接受（用户 2026-11-18 验收反馈）。修订 ADR-0019 的阶段计时与 ADR-0020 的「放弃只能经替换」，ADR-0022 中「确认页期间倒计时已在走」的遗留问题随之解决。

## 决定
1. **听力阶段确认后才开始计时**：有可用完整录音（ADR-0022）的听力阶段，在「开始听力考试」被点击（服务端登记 `study_phase_audio_plays`）之前，阶段没有运行的时钟——状态接口对该阶段返回完整时长，`_advance` 不会因 `expires_at` 已过而封存。首次登记播放时同一事务把 `started_at/expires_at` 重置为 now / now+时限。之后与其他阶段一致（到期按草稿封存）。无可用完整录音的阶段（含逐题兜底）不变，仍从上一阶段结束起计时。
2. **主动放弃考试**：新增 `POST /api/mock-exams/{id}/abandon`（本人、幂等；已完成 409），状态置 `abandoned`，已交阶段答案保留、不生成成绩。说明页的「放弃进行中的考试并重新开始」改为「放弃考试」（放弃后只回到说明页，不自动重开）；考试页答题卡抽屉底部提供「放弃考试」（确认弹窗），放弃后回试卷详情。`replace_active` 参数仍保留于接口但前端不再使用。

## 后果 / 风险
- 确认页可无限停留，时间不流逝；服务端不阻止绕过前端直接存草稿（严格性靠计时线而非防作弊，与 ADR-0022 一致）。
- 不改 Schema。
