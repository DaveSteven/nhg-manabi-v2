# ADR-0023 模拟考试：一份材料一页 + 右侧逐题切换

状态：已接受（用户 2026-11-18 再次确认原方案）。取代 ADR-0021 第 3 条「放得下全显示、放不下才切换」；其余条款（按材料结构分模式、58/42 与 62/38、选项按字数、图片页内放大）继续有效。仅模考页，不改后端与数据。

## 决定
1. 含共享材料（文字/图片/文章填空）的大题，一页只渲染一个 Unit；底部「上一篇 / 下一篇」按 Unit 顺序切换，大题首/末回退为上一大题 / 下一大题 / 交卷。独立题、词汇、文法、听力仍一屏连续作答。
2. 多题 Unit 右栏恒为一次一题：上一题 / 下一题 + `第 N 题 · i/n`，末题的「下一题」换成「下一篇」；单题 Unit 不显示切换条。窄屏同样一次一题。删除高度测量与回滞逻辑。
3. 所有小题保持挂载，切题不重置文章滚动、不丢草稿；切换材料保存草稿，返回时恢复该材料上次的当前题；材料位置（大题 + 篇序号）本机记忆，刷新恢复。
4. 答题卡跳转：切到目标 Unit 并激活目标题（填空题同步高亮 Slot，仅在 Slot 不在可视区时才滚动）。
5. 练习页 `SharedMaterialLayout`（未传 `adaptive`）行为不变，仍用题号条。

## 后果
- 移除 `chipState`、`.is-fit/.is-measuring`；新增 `panel-pager`、`initialActive`、`onNextMaterial`。
- 答题卡仍是已答/标记的唯一状态总览（原题号条上的已答/标记点随题号条在模考中移除）。
