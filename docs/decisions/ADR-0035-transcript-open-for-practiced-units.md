# ADR-0035 已练习过的听力题，原文不再受提交门控

- 状态：已确认（2026-11-24，用户决定）
- 决定：用户此前在**普通/专项或 Quick Practice** 中正式提交过的 Unit（同一试卷任意 Release 下同一 `unit_id`、他人数据不计、严格模考不计），再次练习时听力原文**立即可展开**，不必等本次提交或整次练习结束。
- 范围：**只放开原文**（`GET .../transcript`）。正确答案与解析仍走原门控（即时反馈提交后、统一反馈结束后）；从未练习过的题、严格模考规则不变。
- 实现：后端 `_transcript_gate` = 原 `_feedback_gate` 通过，或存在该用户另一条已提交的同 Unit 记录；会话接口的每个 unit 新增 `previously_practiced`，前端据此放开「原文」按钮（后端仍是权威）。
- 取舍：重做时可先看原文再作答，会降低重练的自测价值，这是用户的明确选择；原文不含答案标注，已提交的题本身已锁定，不影响计分。
