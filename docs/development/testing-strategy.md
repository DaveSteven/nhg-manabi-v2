# 分层测试与验收计划

## 测试层级

1. **结构/转换测试**：Canonical 包 manifest 哈希、数目、外键、RichText slot、媒体引用、重跑幂等；不代表语言学正确。
2. **数据库集成测试（真实 PostgreSQL）**：Alembic 空库升级、回滚、唯一约束、复合 FK、事务失败回滚、release 快照不可改写。
3. **API 测试**：登录授权、内容可见性、禁泄漏答案、提交幂等、跨设备版本冲突、错误码契约。
4. **业务单元测试**：完整 Unit 抽样、跨年份 release 绑定、智能随机软配额、统计正确率、错题历史 B。
5. **React 组件/集成测试**：富文本、cloze、选项选择/锁定、音频播放器覆盖、安全渲染、焦点和空状态。
6. **端到端**：从 N2 试卷目录→Unit→提交→复盘，含刷新恢复、跳过题、模考严守时限。

## 数据库验收集合

- 同包重复导入不会产生第二套记录、release 或来源映射。
- `Question` 不能关联不同 release 的 Unit/Option；正确答案必须属于同题。
- 发布门槛验证失败会回滚并保留可诊断导入错误，不能留下半张试卷可见。
- 草稿更新/正式提交相互隔离、重复提交不双记分；`skip` 的 `is_correct=null`。
- 用户最近错→对→skip，历史曾错仍在，最近有效仍对。

## 核心端到端场景

- 同一个练习抽到多个年份 Unit 时，每个 Session Unit 保存确切 release。
- 即时反馈一篇 3 题、只答 2 题，完整提交后解析才显示。
- 中途刷新后恢复题目顺序、选项和已提交锁定状态；服务端故障时显示保存失败。
- 模考刷新不暂停时钟；正确答案/解析不得出现在前端网络响应。
- 正在练习时管理员发布新 release，历史 Session 仍使用旧版内容。
- 手机底部听力播放器不遮住题目提交按钮，图片题 `prompt=null` 正常展示。

## 视觉回归标准

真实文章长度、日文换行、图片缩放、键盘焦点、移动端 360/390px、桌面 1024/1440px、网络慢/离线、浅色/深色（如启用）。不仅快照组件，还须走查整页。
