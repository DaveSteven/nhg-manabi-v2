# 2026-11-18 模考回顾页紧凑化（ADR-0027 第二轮）

## 范围
按用户新方案把成绩页改为「成绩概览 → 科目卡片 → 筛选 → 题号网格 → 当前题解析」，去掉独立科目统计表与全卷题号墙。仅前端（`MockResults.tsx`、`_practice.scss`、测试），无后端/Schema 改动。

## 改动
- 概览：标签改「已作答正确率」，并写明「已答 X / Y 题；未答不计入正确率也不算错」；仍无换算分/合格判定。
- 科目卡片（tablist）：`已答 X/Y · 答错 X · 正确率 X%`，无有效作答显示「—」；只显示有题的科目。
- 筛选：错误/全部/正确/未答（含计数）；默认错误，该科目无错题时用全部；切科目/筛选自动选首题；题号保持全卷原始编号。
- 复盘：只渲染当前题（`ReviewQuestion`，富文本解析原样）；上一题/下一题在当前筛选内；切题 `scrollIntoView` 到解析区；状态存 sessionStorage（按 session）。
