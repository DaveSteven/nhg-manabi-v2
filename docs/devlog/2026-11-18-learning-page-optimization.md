# 2026-11-18 · 我的学习页面优化（行动导向）

## 范围
把「我的学习」从单纯展示统计转向「发现薄弱项并立即练习」。无 Schema/迁移，无新 ADR（沿用 business-rules 口径；薄弱判定阈值为可调参数，非产品规则）。

## 改动
**后端 `backend/app/api/learning.py`**
- 薄弱题型：只列「有答错且正确率 < 75%」的题型，不再为凑数展示高正确率题型；最多 3 个；有效作答 < 3 次不列出；< 5 次标 `low_sample`（前端「数据较少」），排在样本充足者之后。常量 `MIN_WEAK_ATTEMPTS=3`、`MIN_WEAK_SAMPLE=5`、`WEAK_ACCURACY_BELOW=0.75`、`MAX_WEAK_TYPES=3`。
- 口径未变：正确率 = 答对/(答对+答错)，未答不入分母，无数据为 `null`（显示「—」）；覆盖率按不同 Question 去重。

**前端**
- 概览四指标改名并统一：已作答正确率、题库覆盖率、最近仍错、练习次数；去掉按卡片区分的彩虹色，卡片统一中性底，颜色只表示语义（正确率档位、仍错>0 为红）。
- 「建议先复习 · N 道最近仍错」轻量入口（N 为真实 `still_wrong_questions`，0 时隐藏），进入题目记录（默认「最近仍错」）。
- 按科目：改为整行链接（进入 `/study/practice?subject=…`，等级沿用顶栏当前等级），层次为科目标签 / 覆盖进度条 / 正确率 / 仍错徽标。
- 薄弱题型「去练习」直达该题型：专项页新增 `?type=<question_type_id>` 预选（类型在当前等级不存在则忽略）。
- 练习历史：整行可点进入结果复盘，移除「查看结果」按钮；行内仅名称、来源（专项练习/快速练习/试卷练习）、时间、题数、正确率；提前结束的记录无结果页，不可点；保留分页。
- 题目记录：按钮统一为「重新练习」；仍沿用三个筛选、默认「最近仍错」。重新练习走 Quick Practice 以 `release_id + unit_id` 开整个 Canonical Unit（文章、音频、关联题目齐全）；提交走既有事务，同事务更新 `user_question_progress`，历史错误计数永久保留（既有测试 `test_question_records_follow_strategy_b` 覆盖：答对后转入「最近已答对」，`ever_wrong` 仍保留）。
