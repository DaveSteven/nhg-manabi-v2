# 2026-11-16 · 管理端：试卷管理列表 + 下架 / 恢复上架

## 范围
ADR-0010 取消审核流程、入库即发布后，管理员的安全开关是"随时下架"。本条做后端接口与管理端第一个业务页面：试卷列表、下架、恢复上架。

## 后端
- `withdraw_release` / `restore_release`（`app/publisher.py`）：所有学生可见的出口（目录、大纲、release 单元、媒体、新建练习）本来就要求 `state='published'` 且经 `exam_current_releases`，因此下架 = 状态改 `withdrawn` + 清除 current 指针，一步关闭全部出口；快照与学生已有作答数据不动。恢复在该考试已有 current release 时拒绝（不会悄悄顶掉更新的版本）。决策写入 `publication_decisions`（`withdrawn`/`restored`），只追加不覆盖，`reviewer_id` 为服务端取的 `admin:<id>`。
- 接口（全部需要管理员会话，学生令牌无效）：`GET /api/admin/exams`（状态、版本、Unit 可见/总数、题数、未验证答案数、最近一次发布/下架决策及其备注）、`GET /api/admin/exams/{id}/releases`、`POST /api/admin/releases/{id}/withdraw`（可带原因）、`POST /api/admin/releases/{id}/restore`。错误：404 未找到、409 带稳定 code（`not_published`/`not_withdrawn`/`exam_has_current_release`）、422 非法 id。
- 真实库 105 套的列表查询约 83 ms。

## 管理端
- 新页 `/exams`（侧边栏"试卷管理"）：搜索（年份/月份/编号）、级别与状态筛选、汇总行（共/已发布/已下架/已发布中未验证答案数）、表格（含"N 个隐藏"提示）、下架确认框（可填原因）、恢复确认框；按服务端错误 code 给出中文提示；加载失败/空结果有明确状态。
