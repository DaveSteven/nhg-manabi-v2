# 2026-11-18 · 严格模拟考试：听力播放器

## 范围
ADR-0019 M3：每段音频只播一次、不可暂停/倒退/拖动/倍速、服务器记录播放开始。不含：音频可用性作为开放条件、结果页开放听力原文/解析、自动跳转下一题。

## 设计取舍
- 「只播一次」做成**服务器时间线**：点击播放时在服务端登记 `started_at`，此后位置 = `now − started_at`。这样刷新/断网/切走再回来只能从实时位置续播，不会重头来，也不会因为刷新而永久丢失一段还没播完的音频；播放时长走完即永久消耗。时长缺失时已开始即视为已消耗（不猜测可重播）。
- 不自动播放（浏览器策略且要用户确认准备好）；不自动跳题；播放中允许作答与跳题，离开该大题声音停止、再回来需点「继续播放」。
- 模考不使用普通练习的悬浮 Dock，用独立「严格播放器」卡片（无进度拖动）。
- 服务器无法阻止用户直接请求音频 URL（与练习共用媒体接口）：严格性是产品规则 + 服务端计时线，不是防作弊边界。
