# 严格模拟考试规则（草案，**待用户确认**）

日期：2026-11-17。状态：**草案 / 待确认**。本文不是已确认规则，不得据此上线严格模拟；确认后另写 ADR 并回填 `business-rules.md`。

## 一、现状（核查事实）

- 已确认边界（P-011）：模考与普通练习规则分离；服务器控制时间；交卷前 API 不得泄漏答案；无经核实的时限/音频规则不得启动严格模拟；旧结果永久追溯具体 release。
- 表已存在：`release_exam_phases`（`duration_seconds` 可空、`playback_policy` JSON）、`release_phase_units`、`study_phase_runs`（`started_at/expires_at/closed_at`）、`study_sessions.mode='mock'` + `mock_release_id` + 唯一索引 `ux_one_active_mock`。
- **但真实库中 `release_exam_phases` 为 0 行**：已入库的 105 套试卷没有任何 Phase、时限或播放策略数据；转换器目前不产出 Phase。practice 提交接口对 mock 会话直接 409 `not_a_practice_session`，模考无任何接口与前端。
- 因此严格模拟的前置不是代码而是**规则与数据**：每个级别各 Phase 的时限、听力播放规则，以及把它们写入 Release 的途径。

## 二、需要你确认的决定

| # | 问题 | 建议默认（均待确认） | 影响 |
|---|---|---|---|
| M1 | Phase 划分与时限（按级别） | 沿用官方考试结构：N1/N2 为「言語知識（文字・語彙・文法）・読解」+「聴解」；N3/N4/N5 为「言語知識（文字・語彙）」「言語知識（文法）・読解」「聴解」。**各 Phase 具体分钟数需你提供或以官方公布为准，我不凭记忆写入** | 决定 Phase 数据与计时 |
| M2 | 时限数据放哪 | 放进 Canonical 包/Release 的 `release_exam_phases`（不可变，随 release 版本化），由转换器按级别规则表生成；规则表本身入库并写明来源 | 需要转换器与导入改动；旧 release 不回改，新 release 才有 Phase |
| M3 | 听力播放规则 | 严格模拟：每段音频只播一次、不可暂停/倒退/拖动、倍速关闭；音频结束即锁定该题组；服务器记录播放开始时间 | 与普通练习听力播放器分离，需单独播放器模式 |
| M4 | 超时 | 服务器 `expires_at` 到期自动封存当前 Phase：已有草稿以已选答案正式提交，未选为 skip；客户端倒计时仅展示 | 刷新/断网不重置计时 |
| M5 | Phase 间规则 | 按顺序进入，Phase 关闭后不可回看/修改；提前结束某 Phase 的是否剩余时间顺延——建议**不顺延** | 影响计时与 UI |
| M6 | 暂停/断网 | 不可暂停；断网期间计时继续；重连按服务器时间恢复 | 与「关闭页面不等于结束」一致 |
| M7 | 成绩呈现 | 仅显示各 Phase/科目的答对数与正确率；**不做官方换算分**（P-011 已禁伪造）；模考与练习成绩分开展示 | 不混入练习统计 |
| M8 | 名额 | 严格模考单名额；**是否允许与练习会话同时占用**（business-rules 已标「须确认」）——建议允许（互不影响），开始新模考时旧模考需用户确认后才放弃 | 决定冲突弹窗 |
| M9 | 答案泄漏边界 | 交卷（最后一个 Phase 关闭）前，任何接口不返回 `correct_option`、解析、听力原文；交卷后才开放逐题回顾 | 需专门的模考题目 DTO，不复用 practice 的 unit 接口 |
| M10 | 可上线范围 | 先只开放「规则与数据齐全」的级别/试卷；缺 Phase 的试卷不显示模考入口 | 与「无可靠时限不开放」一致 |

## 三、建议的实施顺序（确认后）

1. 你确认 M1–M10（M1 提供分钟数或认可以官方公布为准）→ 写 ADR（模考规则）并回填 business-rules / feature-scope / page-structure。
2. 转换器与导入：规则表 → Phase 数据 → 新 release；`release_phase_units` 归属校验（每 Unit 只属一个 Phase）。
3. 后端：创建模考（Phase 0 开始计时）、服务端 Phase 状态机与超时封存、模考专用 DTO（无答案）、提交/交卷、结果（含 release 追溯）。
4. 前端：说明页 → 计时器（服务器时间校准）→ 严格听力模式 → 交卷与成绩页。
5. 测试：计时/刷新/超时、答案泄漏扫描（交卷前所有接口）、并发、Phase 顺序与不可回看。
